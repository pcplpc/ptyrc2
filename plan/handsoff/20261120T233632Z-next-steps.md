## What this session learned about piloting

- Two agents at once with disjoint grounds named in each brief: no
  lost work, no broken HEAD. A shared file went to one agent by name
  when asked (`build.rs`).
- The pilot staged a file and committed in a second command: an
  agent's plain commit took it. Stage and commit in one command line;
  the check of `git diff --cached` does not cover the pilot.
- A final check under load still hides things: `storeapp` was called
  flaky for a day and had a cause. A test red twice is debugged.
- The full run is quiet only once the load has fallen: wait for it
  (`/proc/loadavg` under 4) before starting.
- Reading an earlier session's transcript for its briefs was refused
  by the harness: save the briefs worth keeping in `temp/`.
- Disk: 93 GB free at the end (90 %); `target/` grew 4 GB in the
  session.
