## Facts worth knowing

- The post-commit timestamp hook stashes unstaged files while it runs.
  Siblings must not share one tree: `git worktree add -b fork/<topic>
  temp/wt-<topic> main` from inside the repository, then merge into
  `main` (no rebase: the hook stamps commit hashes). An HTTP 429 from the
  hook is harmless.
- The five worktrees `temp/wt-*` and branches `fork/*` of this session
  still exist, all merged: `git worktree remove` and `git branch -d` when
  no longer wanted.
- Siblings ran to 170k-290k tokens on these briefs: three of five passed
  the 200k bound. Give a sibling one topic, not two.
- `vim` is a shell alias here: `/usr/bin/vim`. `/home/peon/.git` is a
  guard. Test hosts are detached tmux sessions with unique names.
- New names for "did you mean" go in `rust/ptyrc-server/src/hints.rs`.
