## Facts worth knowing

- The post-commit timestamp hook stashes unstaged files while it runs.
  Siblings must not share one tree: `git worktree add -b fork/<topic>
  temp/wt-<topic> main` from inside the repository, then merge into
  `main` (no rebase). An HTTP 429 from the hook is harmless.
- Worktrees `temp/wt-*` and branches `fork/*` of the second and fourth
  sessions still exist, all merged: `git worktree remove` and
  `git branch -d` when no longer wanted.
- Siblings ran to 150k-230k tokens, one topic each. Tell a running
  sibling when `main` moved under its files; it merges `main` itself.
- In zsh, `for s in "x.sh --check"` does not split: run scripts with
  their flags unquoted.
- `vim` is a shell alias here: `/usr/bin/vim`. Test hosts are detached
  tmux sessions with unique names.
- New names for "did you mean" go in `rust/ptyrc-server/src/hints.rs`.
